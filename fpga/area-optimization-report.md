## ① 项目当前状况（架构 / 技术 / 资源）

### 1.1 一句话定位

一个面向 **chiplab / xc7a200t** 的 **RV32GC 4-发射乱序（OoO）处理器**（项目内代号 2B），当前处于**后端面积优化**阶段：已从 366,483 LUT（272.28%）压到 **126,699 LUT（94.13%，累计 −65.43%，已低于器件容量）**，目标 ≤80%（107,680 LUT 仍差 −19,019）。

### 1.2 架构（微架构框架）

```
front4 前端（4 宽取指/译码 + 分支预测 + I-Cache + fetch；BTB 写模式 N25fix 已与行为模型对齐）
   │  一次取 4 条指令（用户底线，不允许改）
   ▼
back2 后端（乱序执行）
   ├ rename ×2（整数/浮点分离；RAT + checkpoint RAT 快照 + free-list）
   ├ 6 个分布式发射队列 IQ（ALU0/ALU1=12、BRU=6、MDU=6、LSU=8、FPU=6；np_q 2W bank）
   ├ 整数 PRF 64×32（11 读口/4 写口）+ 浮点 PRF 64×64（5 读口/2 写口）——N15 固定 2:1 合并后
   ├ ROB 64 项（宽载荷入 4-bank SDP BRAM + 2-entry 退休窗；同址读写由 dang_hit 地址守护承重）
   ├ LSQ：SQ 32 / LQ 8（**store→load 转发已移除（N29B）**：依赖 load 等 older store drain→L1D 写完成再访存；内存路径非对齐/跨字两拍取数仍在（0a4b178））
   └ 6 个执行部件：ALU0 / ALU1 / BRU / MDU / LSU / FPU（**唯一共享 53-bit FMA 核（N27B，u_fma**）+ cvt + div/sqrt + cmp）
   ▼
2 宽提交（2-wide commit，4-issue ≠ 4-commit）→ 分支训练（trq，单写口 FIFO）
```

- 关键结构参数（当前 HEAD `d00eb03`）：整数物理寄存器 **NREG_I=64**（PDW_I=6bit）、浮点 64（6bit）、ROB 64（**窄表 nq 36→16 bit（N35B）**，typed 四表 + ev_mem 已 LUTRAM）、SQ 32、LQ 8、IQ 总容量 50（np_q 2W bank）、checkpoint 16、**commit 2-wide（分配 4-wide）**、free-list FL_DEPTH=64、FMA 共享 53-bit 核（fma_s/d 保留金标）、div/sqrt 收尾舍入并入 u_fma（N33B）、PRF 读口 11/5、**store→load 转发已移除（N29B）**、前端 LHT/ev_mem/rob typed 四表 LUTRAM（N34B-1/3）。
- 流水线：前端 4 宽取指 → rename（4 宽分配）→ IQ 唤醒/选择（4-wide issue）→ 发射 → 执行 → 写回（4 写口）→ **2 宽提交**。

## ② 主要问题与成因

### 2.1 核心问题：LUT 超 80% 目标——Gate E 后已破器件容量（94.13%），结构收窄仍缺 −19,019

**事实**：当前 126,699 LUT = 94.13%（首破器件容量），到 ≤80%（107,680 LUT）仍差 **−19,019 LUT（−15.0%）**。

**成因（用数据印证）**：

**(a) 结构级面积归因——旧 `area_attrib_nreg.md` 表已过时，Gate C（N16A/N20/N21A/N22A/N23A）给出当前真值**：

- **三种 LUT 口径不可混减**（N20；唯一净收益判据 = 全核 Slice LUT **138,593**，Gate D 后新基线；Gate C 时为 143,992）：raw 原语口径（Gate C 时 155,509，×0.9259≈Slice，折算比随网表/层级变）在新树需重测，旧 N11 raw 158,544（绑定 n10 网表）已失效；基线时 A−B=11,517 是 LUT combining/物理归属口径差，**不是可回收面积**。
- **NAME 桶/容器名在 flatten_hierarchy=rebuilt 下是改挂/重名桶，禁止立项**（N16A 实测同参数实例容器差 617~2,716 LUT）。代表性修正：
  - `mem` 13,061 **不是 PRF 存储体**：PRF 阵列 we/waddr/wdata 直连 FF（写路径反向锥 = 0 LUT）；真成分 = u_iwmem 读回交叉开关 6,678 + u_fpu **FDIV/FSQRT 迭代通路** 4,346 + u_prf_i 读 mux 1,088。**PRF 读选择真实成本 = 10,336 raw LUT**（544/32b 读口、1,088/64b 口；写口仲裁 92）。
  - `ld_hd` 名下 **LUT = 0**（512 FF 载荷窗口），8,850 全来自 `fwdp_data`——**二者是同一棵树（共享 99.4%），不可相加**；转发通路上界 = K_LSU_FWD 反向锥 10,643（26.2% 与 K_LSU_MISC 共享）。
  - `DISPATCH` 8,403 = 前端读 D1 载荷（d1_uop_q 99.6% 在 u_front）；"6 IQ 窄锥 6,990"后被 N23A 证明为**解析截断假数并作废**（rebuilt 别名网驱动解析失败；修正后六锥并集 34,092、互不可加）。
  - `u_ren_f` 最大匿名锥 3,091 = **dispatch→IQ 入队胶合云**（非 rename 的 RAT/回滚/free-list；RAT 类独占 0）。
  - WRITEBACK/COMMIT（N8 后 209/0 LUT）：仍**不存在可单独砍的 writeback/commit 结构**。
- 本轮锥间共享仅 4.4%（K_LSU_FWD×MISC；next-state 窄锥口径）vs N16A 的 84.88%（NAME+前向闭包宽锥口径）——**两个数字都成立但口径不同，引用必须带口径声明**。

**(b) "共享/时分复用"会新增路由代价，反超存储省量（三个铁证）**：

| 实验 | 方向 | 实测净 | 结论 |
|---|---|---:|---|
| EXP-A PRF 读口 16/8→4/2 + Operand Collector | 时分复用 | **+46,479 LUT** | 负（已回退） |
| EXP-C IQ 6→3 集群 | 共享存储 | **+2,337 LUT** | 负（已回退） |
| N21B-K1 3-lane 抢 2 口折叠 | 让位复用 | 局部 −2,378 → **全核仅 −1,249** | 负（回退；3:1 地址 mux + 让位网吃掉一半收益） |

**(c) "全局重映射噪声"会吞掉小杠杆（反复出现）**：D1 局部 −4,835 全核仅 −1,434；EXP-R3c 局部 −174 全核 **+1,392**；N4 写口 6→4 归因脆弱（u_prf_i 自身 +2）。⇒ **本轮起统一门槛 = 全核净 ≥1.5k Slice（N20 §5），低于此一律不采纳/回退。**

### 2.2 堵点：Gate C 封存论经 Gate D 修正——转发通道"封死"结论被**推翻**，FMA 通道被打通

- **已被容量数据否决**：SQ 32→16（高水位 20）、检查点压缩 ≤4（池满 16）、FPU iterative div/sqrt（占忙拍 51%）、N5 IQ 合并（ALU0+ALU1 在 ipc_alu4w 同发 22>12）。
- **Gate C 封存（全部维持）**：存储包装 glue（真实仅 21 LUT）、rename 匿名锥重构、唤醒矩阵共享（无公共子项 + 在关键路径带）、FMA S/D *控制* 共享（控制仅 60/102 LUT）、np_q BRAM（1,900bit/单写口/读侧 mux 不减）、SQ banking、保守转发 N12B、dispatch 预译码 N23、PRF 读口继续收窄 N21B/K1（提交级口不可让位 + 3-lane 抢 2 口真让位超界）。
- **★ Gate D 修正与达成（Gate C 曾判"转发通道已封死"——N29A 证明该论的依据"融合 91.6%"只是输入侧融合；输出侧 8,240 raw 无任何保留逻辑读它们）**：
  - **转发通道打通**：`ld_hd` 名下 0 LUT（纯 FF 窗口）、"纯选择"仅 183~677 Slice 这两条 Gate C 结论对，**但它们约束的是"更换转发实现"，约束不了"删除转发功能"**——纯等待变体（N29B）实测 **−3,570 LUT** 且 IPC/C5 达标；
  - **FMA 主通路打通**：Gate C 只冻结了"控制共享"（N13A），Gate D 的"主通路共享"（N27B）实测 **−1,829 LUT** 且 IPC/C5 零变化；
  - **仍封存**：PRF 单口继续收窄（≈312 LUT/口 × 只剩 4 口，单轮 ≥1.5k 不可达）、iwm 交叉开关（940+605 raw、综合=理论下界）、ROB 减深（64→48 fail-closed：5 档实测顶满 64）、SQ banking 与 eqv-mux 重写类。
- **教训（写死到流程）**：**"局部锥融不通 ≠ 结构不可动"——是"保持功能的前提下可删除的完整对象"决定收益； 对每个候选必须先问"删掉的物全是为什么存在"，而不是"能不能再分一棵树"**（N29A 的输出侧可删性判据 + N30 表为标准流程）。

**结论（有数据支撑）**：366,483→126,699（−65.43%）来自六类真实结构改动：删完整单元/主通路径（C1/N8/N27B/N33B）、级联减宽（NREG/N1/N3/N4/flist_q/N35B-nq）、互斥路径合并（N15）、**删除整段功能并以时序语义兜底（N29B 转发移除）**、**实现修复（N34B-1/3 把要 LUTRAM 的表脱异步复位 dword）**。剩余 −19,019 缺口待 §③ 三个方向：候选 1（综合配方）、候选 2（K1，on old-tree base）、N34B-2（LOCAL，patch 复原 ≤−915+送审需求冲突），以及"再造一个 N27B/N29B 级的完整功能/重复块"（须重新扫描）。

## ③ 可能的解决方案与优化路径

**最新口径（2026-10-04 用户拍板）**：
> 4 发射 + chiplab/xc7a200t 是底线；前端一次取 4 条指令（hard）；**后端至少一次提交 2 条指令，即底线 IPC ≈ 2**（hard）；**FU 数量、资源占用率、时钟频率可改，但需用户审阅**。

已按此完成的**结构宽度重构**（Gate A 阶段，answer.md §十六）：
- **N1 commit 4→2**（−16,022 LUT）：ALLOC_W=4/COMMIT_W=2 两真源分离，退休选择/free-list 回收/架构更新全 2 宽，IPC=2.0 未伤。
- **N3 ROB 退休窗 8→2**（−2,677 LUT）：提交读零 mux，win_q 2125→234 LUT。
- **N4 PRF 写口 6→4**（−3,171 LUT，归因脆弱）：ALU0/1/BRU 直连 + LSU>MDU>FPU 共享口。
- **flist_q 128→64**（−2,093 LUT）：2× 余量裁剪。
- N2 BRU merge 砍掉（FU_ALU=FU_BRU=0 无面积靶子）。

**已完成的"数据通路压缩"（answer.md §十六-十七，N6-N10）**：
- **N8 FADD/FSUB/FMUL 并入 FMA**（−5,679 LUT/−2,190 FF/−11 DSP）：删 4 个完整单元（add_s/add_d/mul_s/mul_d），真实结构删减；FMUL 零符号用 `c=±0 且符号=积符号`（IEEE 乘法零符号恒=操作数符号异或，FMA 零和才受 rm 影响）。
- **N10 np_q 写口 4W→2×2W bank**（−960 LUT）：均衡直写+余量背压，43% 局部被重挂吞。
- N7 SQ banking 负（关闭）：banking 只改树分组、不减叶子，动态候选削减≠LUT。
- N9 LSU_CDQ 归因：是提交排空 FIFO（非 CAM），N1 已降到 6.3k；②"1 入队"负（net −349 落噪声带）。
- div/sqrt：非面积杠杆（114 拍=位串行最小，参数 32 是死参数，修快反加面积）。

**已完成的"Gate B 数据通路压缩"（answer.md §七，N11-N15）**：
- **N11 面积归因重建**（只读）：独立 LUT 23,627（14.9%）/共享≥2 cone 134,540（84.9%）/未归因 377 ⇒ **84.9% LUT 在多结构 cone 交集，结构 LUT 数不可当可相减收益**（"局部省了全核没降"的根因）。
- **N12A/N12-stress + 两处正确性修复**（净 −612 LUT）：非对齐 load 全转发写回值字节错位（`e66241d`）+ ≤4B 非对齐跨 4B 字边界访存缺口（`0a4b178`，复用 8B 两拍机制）。
- **N15 PRF 读口 16/8→11/5**（−2,868 LUT，本轮最大正收益）：3 组"零冲突固定 2:1 合并"（ALU1∪MDU、LSU存数据∪FPU整数源、FPU c∪LSU浮点存数据），只加 6bit 地址 mux、无全局 crossbar；动态 20 程序 49,116 拍 0 冲突、IPC 无损失。
- N12B 保守转发负（回退）：删了逐字节合并树（ld_hd 8.7k→0）但被"胜者 32:1 数据 mux"抵消，net ≈0。
- N13A FMA S/D 控制共享无靶子（控制仅 60/102 LUT）；N14 np_q BRAM 停（1,900bit 太小、单写口、读侧 mux 不减）。

**已完成的"Gate C 靶子筛选"（answer.md 2026-10-14 版 §一~§六，N16A~N25；本轮净面积变动 = 0，全部为实证筛选/口径治理/正确性收口）**：

1. **N20 口径归一（必做前置，完成）**：Slice 143,992（唯一收益判据）/ raw 155,509（×0.9259，折算比随网表/层级变）/ 旧 raw 158,544 作废；唯一 cell 分区 Σ 闭合 diff=0；→见 §②(a) 三桶修正。
